# StemTutor

Тренажёр для мини-MIDI-клавиатур (AKAI MPK mini и др.) для тех, кто не учился музыке. Треки
на 25 клавишах собирают так же, как в роликах «как сделан хит»: каждую дорожку записывают
отдельно, короткими кусками, которые потом крутятся по кругу. StemTutor берёт трек, раскладывает
его на дорожки, а дорожку — на слои для **одной руки** (мелодия, аккорды, бас), подбирает
**одну октаву (OCT) на кусок** — переключать во время игры ничего не нужно — и учит играть кусок
за куском. То, что вы сыграете, ложится в любой DAW (Ableton и т.д.) дорожкой, совпадающей
с оригиналом по нотам и сетке. **План кавера** проводит по всему треку: какие дорожки записать,
в каком порядке, какие петли выучить и куда скопировать их клипы — в конце в Ableton звучит
ваш трек, сыгранный своими руками. По желанию план уточняет **ИИ-продюсер** (нейросеть через
OpenRouter, свой ключ). Отдельно есть встроенные уроки аккордов и разминка для пальцев.

## Быстрый старт

Нужно: Windows 11, [uv](https://docs.astral.sh/uv/), ffmpeg, Chrome или Edge. Если uv не найден,
`start.bat` сам предложит поставить его через winget. Node.js нужен, только когда готовой сборки
интерфейса (`frontend\dist`) нет — например, после `git clone`, — или для пересборки (`--rebuild`).

```
winget install astral-sh.uv
winget install Gyan.FFmpeg
```

Запуск — двойной щелчок по **`start.bat`**. Первый раз ставятся зависимости (~1–2 мин, с модулем
разделения — дольше, см. ниже), потом открывается `http://127.0.0.1:8765`. Окно консоли не
закрывайте, пока работаете. Если StemTutor уже запущен, повторный `start.bat` просто откроет его
в браузере.

Флаги `start.bat`: `--with-separation` / `--without-separation` (модуль Demucs),
`--repair-separation` (переустановить PyTorch и Demucs, если модуль сломался), `--rebuild`
(пересобрать интерфейс), `--port 8766` (если порт 8765 занят другой программой). Флаги
срабатывают, когда StemTutor закрыт: закройте его окно и запустите `start.bat` с флагом.

С нуля проще всего начать с раздела **Аккорды и разминка** — 14 встроенных уроков, загружать ничего
не нужно. Первый урок с треком без поиска файлов: **Новый урок → Готовые материалы** → перетащите
`samples/Demo Song.mid` (или четыре файла из `samples/stems`).

## Как пользоваться

1. **Клавиатура.** Выберите контроллер, подключите его по USB — нажатия подсветятся на рисунке.
   Если менялся пресет в MPK Editor — пройдите **Калибровку** (приложение спросит «нажми левую
   клавишу», «ударь пэд 1…» и запомнит реальные ноты).
2. **Новый урок** — два пути:
   * **Готовые материалы.** MIDI-файл трека (MuseScore, BitMidi, VGMusic для игровой музыки…) —
     самый точный путь: ноты берутся из файла. И/или стемы (WAV/MP3) — тогда ноты распознаются.
     Можно добавить оригинал (ссылку или файл), чтобы играть поверх записи.
   * **Автоматически.** Ссылка (YouTube, SoundCloud…) или аудиофайл → разделение на стемы →
     распознавание. Нужен модуль разделения (см. ниже).
3. **Урок.** Проверьте сетку кнопкой «Проверить сетку»: метроном должен совпасть с треком, акцент —
   с «раз». Если нет — BPM, ×2/÷2, «← доля / доля →».
4. **Учить →** по дорожке:
   * **Что играем.** Если партию не сыграть одной рукой, она разложена на слои: *Мелодия*
     (верхние одиночные ноты), *Аккорды* (собраны так, чтобы взять одной рукой: до 4 нот в пределах
     октавы), *Бас* (нижние ноты). Каждый слой учится и записывается отдельной дорожкой. Если
     мелодия звучит верхними нотами аккордов, её можно вынести в слой галочкой.
   * **Кусок.** По умолчанию выбрана «главная петля» (★ — кусок, который повторяется чаще всего).
     Другой — блоком в «Из чего состоит дорожка» (Shift+щелчок — несколько подряд), протяжкой
     мышью по ленте нот или двойным щелчком по такту (Alt — по долям). На паузе ленту можно
     листать колёсиком или ↑ ↓ (Ctrl + колёсико — масштаб), клавиши показывают ноты под линией.
   * **Октава.** Для куска подбирается одна настройка OCT; если какие-то ноты не влезают в 25 клавиш,
     они сдвинуты на октаву (пунктир). Новый кусок с другой октавой — подсказка вверху.
   * *Подготовка* — какую октаву поставить, раскладка пэдов (можно поменять), что учим.
   * *Послушать* — ноты падают на клавиши, звучит оригинал партии или синтезатор.
   * *Разучить* — время стоит, пока не нажмёте правильные ноты; ошибка октавой → подсказка.
     Галочка «аккорд — всеми клавишами вместе» засчитывает аккорд, только когда он зажат целиком.
   * *Играть* — по кругу: каждая нота оценивается («точно / хорошо / около / мимо»), длинные нужно
     держать до конца, после круга ≥ 90% темп растёт на 5%. Без «по кругу» кусок играется один
     раз, потом итог. Пауза и «Продолжить» не сбрасывают игру.
   * *Записать в DAW* — «MIDI этого куска» (готовая петля с начала клипа), MIDI всей партии
     (каждый слой — отдельной дорожкой), минусовка и стем (WAV под сетку DAW) и пошаговый гайд.
   Задержка звука (наушники, драйвер) учитывается автоматически; если нажатия всё равно
   стабильно опаздывают или спешат, приложение предложит поправку (панель справа в «Играть»).
   Пробел — старт/пауза. Без контроллера можно щёлкать мышью по рисунку устройства.
5. **План кавера** (кнопка на странице урока) — трек целиком, шаг за шагом:
   * дорожки в порядке записи: ударные → бас → аккорды → мелодия; каждая — один слой для одной
     руки, со звуком, с которого начать в браузере Live («Sounds → Bass», «Drums → Kit»…), и OCT;
     голос и почти пустые дорожки по умолчанию выключены — их можно включить;
   * для каждой дорожки — карта трека (A A B A…) и петли — те же куски и буквы, что в «Из чего
     состоит дорожка» тренажёра (затакт перед первым тактом — отдельным куском): «Учить →» открывает
     петлю в тренажёре, круг в «Играть», сыгранный целиком от 85% на темпе от 90%, отмечает её
     выученной (галочку можно поставить и снять вручную), «MIDI-образец» — петля для сверки; затем —
     куда скопировать клип. Такты пишутся как в тренажёре и, если отличаются, как в Ableton;
   * ударные: на какие ноты положить звуки набора в Drum Rack, чтобы пэды попали в нужные звуки;
   * «эталон: MIDI всех дорожек» — один файл со всеми дорожками плана (и теми, что не записываете
     сами); положите его с такта 1, Live разложит его по MIDI-дорожкам; «трек WAV» — оригинал под
     сетку, для сверки;
   * прогресс сохраняется в уроке.

   **ИИ-продюсер** (по желанию). Вставьте свой ключ с [openrouter.ai/keys](https://openrouter.ai/keys),
   выберите модель (в списке только те, что умеют отвечать по строгой схеме; 🎧 — умеет слушать
   звук; рядом — примерная цена одного плана) и нажмите «Спросить ИИ-продюсера». Нейросеть получает
   разбор трека (темп, аккорды по тактам, дорожки, петли с первыми нотами — его можно посмотреть
   до отправки), по желанию название трека, исполнителя и имена дорожек и до 30 секунд звука, и
   отвечает строго по схеме: названия
   дорожек, что включить, порядок, звуки в Ableton, как упростить, советы к петлям. Ноты, такты и
   октавы она не меняет — их считает программа; ответ проверяется (чужие id и лишнее
   отбрасываются) и хранится в уроке.
6. **Аккорды и разминка** — встроенные уроки для одной руки, везде OCT 0: первый аккорд, C–F–G,
   минор, мажор и минор, популярный и мрачный круги, напряжение, пустые и sus-аккорды, тёмный
   минор с чёрными клавишами, аккорды из 4 нот, арпеджио; разминки «пять пальцев», минорная
   позиция и пентатоника. На нотах — номера пальцев (1 — большой … 5 — мизинец), в аккордовых
   уроках аккорд засчитывается, только когда зажат целиком, а «Что я нажал?» называет любой
   зажатый аккорд. Незнакомые слова — в разделе **Словарик**.

Обработку можно остановить: «Отменить» в списке уроков или «Отменить обработку» на странице
урока; «Повторить» запускает её заново. Урок в очереди отменяется сразу, идущий — за секунду-две
(во время первой загрузки модели — когда она докачается).

### Где взять стемы

* **Ableton Live 12.3 Suite** — встроенное разделение: правый клик по клипу → *Separate Stems*
  (Vocals, Bass, Drums, Other), затем экспорт дорожек в WAV.
* UVR (Ultimate Vocal Remover), Moises и подобные.

Имена файлов определяют роль: `drums`, `bass`, `vocals`, `other`, `piano`, `guitar`
(можно по-русски: «ударные», «бас», «вокал»…). Роль всегда можно поменять в уроке.

### MPK mini и Ableton одновременно

В Windows 11 24H2/25H2 с Windows MIDI Services (вышла в феврале 2026) один контроллер доступен
нескольким программам сразу. Если StemTutor пишет «Порт занят»: обновите Windows, или тренируйтесь
в StemTutor с закрытым DAW, а записывайте потом, или отдайте MIDI-выход трека DAW в StemTutor через
loopback-порт. Галочка «звук моей игры» озвучивает нажатия, если DAW закрыт.

### Модуль разделения на стемы (Demucs)

По умолчанию выключен. Включить — `start.bat --with-separation`: выбор запоминается файлом
`.with-separation` рядом со `start.bat`, и запуск дополнительно скачает PyTorch с CUDA (~2 ГБ)
и Demucs 4.1. Отключить — `start.bat --without-separation`.

При создании урока «Автоматически» выбирается модель (скачивается при первом использовании
в `%USERPROFILE%\.cache\huggingface`):

| Модель | Стемы | Когда брать |
|---|---|---|
| **htdemucs_ft** (по умолчанию) | drums, bass, vocals, other | лучшее качество ударных и баса |
| htdemucs | те же 4 | примерно в 2 раза быстрее, чуть хуже |
| htdemucs_6s | + piano, guitar | если в треке важны отдельно пианино и гитара (у этих стемов больше «протечек») |

Замер на RTX 5080, трек 4 минуты: разделение htdemucs_ft — 16 с, htdemucs — 7 с; весь урок
«Автоматически» (разделение + распознавание + подготовка аудио) — около 35 с. Без учёта первой
загрузки модели. На CPU — в разы дольше. Без модуля всё остальное работает: стемы можно сделать
в Ableton 12.3 Suite.

## Безопасность

* `start.bat` работает с правами пользователя (без администратора), не трогает реестр, службы,
  автозапуск и брандмауэр. Пишет только в `%LOCALAPPDATA%\StemTutor`, кэш uv, `%TEMP%` и папку
  проекта.
* Пакеты ставятся строго по `backend\uv.lock` и `frontend\package-lock.json` (версии и хэши
  закреплены) из PyPI и download.pytorch.org; uv — через winget и только после вашего «Y».
* Сервер слушает только `127.0.0.1` и принимает запросы только со своих страниц: чужой сайт
  в браузере не может управлять StemTutor (проверка Host/Origin/Sec-Fetch-Site).
* Для YouTube yt-dlp выполняет JavaScript плеера в песочнице Deno или Node (`--permission`,
  без доступа к файлам и процессам); Bun без песочницы не используется.
* Скачанное аудио декодирует ffmpeg — держите его обновлённым: `winget upgrade Gyan.FFmpeg`.
* ИИ-продюсер выключен, пока вы сами не вставите ключ OpenRouter. Ключ хранится только на этом
  компьютере (`ai.json` в папке данных), страницам приложения не отдаётся (видны только первые и
  последние символы) и уходит только в OpenRouter. Запрос отправляется только по кнопке (пока он
  идёт, второй по тому же треку не отправится); что именно уйдёт — видно в «Что уйдёт в
  нейросеть»; название, исполнитель и имена дорожек, а также звук — отдельными галочками (без
  первой галочки дорожки называются только по роли: бас, аккорды…).

## Данные

Уроки и настройки — в `%LOCALAPPDATA%\StemTutor\data` (там же `ai.json` с ключом OpenRouter, если
вы его вставили), Python-окружение — в `%LOCALAPPDATA%\StemTutor\venv` (короткий путь: длинные
пути ломают загрузку DLL в Windows).

Удалить всё:
* `%LOCALAPPDATA%\StemTutor` — уроки, настройки, окружение;
* `%USERPROFILE%\.cache\huggingface\hub\models--adefossez--*` — модели Demucs (~0.5 ГБ);
* `uv cache clean` — кэш пакетов uv (там же скачанный PyTorch, ~3 ГБ).

## Известные ограничения

* Распознавание нот не идеально: чем «чище» стем, тем лучше. Готовый MIDI всегда точнее.
* Ударные распознаются как kick / snare / закрытый и открытый хэт / крэш; томов пока нет.
  Малый барабан с очень низким «телом» (около 150 Гц) может продублироваться бочкой.
* В аккордах на детюненных и тремоло-пэдах под мелодией нота иногда «переударяется» посреди
  такта — в туториале её можно просто держать.
* Сетка по аудио рассчитана на ровный темп и размер 4/4 (правится вручную).
* Готовый MIDI может не совпадать с записью по темпу — есть ручной сдвиг записи; авто-выравнивание в планах.
* Синхронизация с транспортом DAW по MIDI Clock — в планах (сейчас запись идёт поверх скачанной минусовки).

## Разработка

```
cd backend
uv sync --extra separation   # без --extra uv удалит модуль разделения из окружения
uv run pytest            # импорт MIDI, API, распознавание и разделение на синтетических стемах
cd ../frontend
npm ci
npm test                 # движок раскладки, сетка, теория, паттерны, MIDI-файлы
npm run dev              # интерфейс на :5173 с прокси на сервер :8765
npm run build            # сборка в frontend/dist (её раздаёт сервер)
```

Если проект лежит в очень длинном пути, задайте короткое окружение — в cmd:
`set "UV_PROJECT_ENVIRONMENT=%LOCALAPPDATA%\StemTutor\venv"`, в PowerShell:
`$env:UV_PROJECT_ENVIRONMENT = "$env:LOCALAPPDATA\StemTutor\venv"`.

```
backend/stemtutor/
  server.py            API + раздача интерфейса
  producer.py          ИИ-продюсер: ключ, промпт и схема, вызов OpenRouter, проверка ответа
  storage.py, jobs.py  хранилище уроков, фоновая обработка
  importers/           MIDI-импорт, роли дорожек
  pipeline/            fetch (yt-dlp) · decode/encode (ffmpeg) · separate (Demucs, опц.)
                       analyze (доли, темп, сильная доля) · melodic (basic-pitch ONNX) · drums
frontend/src/
  music/               сетка, теория, паттерны, слои для одной руки и октава на кусок, MIDI-экспорт,
                       простые слова (explain.ts)
  builtin/             встроенные уроки аккордов и разминки
  cover/               план кавера: дорожки, петли и прогресс (plan, progress), сводка для
                       нейросети и проверка её ответа (producer)
  instruments/         профили контроллеров и их геометрия
  midi/, audio/        Web MIDI, транспорт, синтезатор
  tutorial/            сессия туториала (режимы, оценка)
  pages/, components/  интерфейс
```
